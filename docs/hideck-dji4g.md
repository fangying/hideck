# DJI 4G / QDC507 在 HiDeck 下的方案

当前方案以 [hideck-qc507.md](../hideck-qc507.md) 为准，部署细节见 [按通话音频生命周期说明](../packaging/qdc507/CALL-SCOPED-AUDIO.md)。

原调试文档的常驻音频路由、容器等待 audio ready、混用 QMI/AT 通话状态等步骤已经被替换，请勿继续按旧版本操作。

当前分工：QMI 负责上网与短信；USB AT 控制呼叫并用 CLCC 识别语音状态；宿主 broker 在通话接通后通过 ADB 准备 D4/UAC；ALSA 与 WebRTC 传递音频，挂断后自动释放路由。

正式部署版本已完成呼入、外呼手机端听测，以及两轮整机温重启后的自动恢复与外呼听测；第二轮重启后的呼入听测也已通过。手机回传语音内容、长期稳定性和断电冷启动仍需单独验证。文档不包含内部地址、号码、密码或通知配置。
